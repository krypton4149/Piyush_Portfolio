## 🧰 Tech Stack

- **React 18** – Component-based UI framework
- **Vite** – Fast development and bundling
- **Styled JSX** – Scoped component-level styling
- **Flexbox & CSS Grid** – Responsive layout system

---

## 🧩 Sections

1. **Hero** – Personal introduction with CTA buttons  
2. **About** – Summary and skills with animated bars  
3. **Experience & Education** – Work history and academic background  
4. **Projects** – Filterable list with live demo and GitHub links  
5. **Contact** – Functional contact form with validation  
6. **Footer** – Email, phone, social links, and copyright

## 📝 Features

- 🎨 Elegant & Modern Design
